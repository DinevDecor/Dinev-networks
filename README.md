## Отопление — подово на ток (Ekotermal + INTIEL) ⏳ в процес
**Инсталация:** проточен електрокотел **Ekotermal MRL/K ~10 kW, трифазен** (без буфер) захранва подовото. Бойлерът за БГВ е отделен (проточен трифазен — НЕ се пипа). Стаен термостат: **INTIEL INTO140D** — **пропорционален** (модулиращ), да НЕ се сменя.

**Как е вързан термостатът (от схемата на Ekotermal MRL/K):**
- INTIEL „OUT" (3 жила) → клеморед **X9** на котела (пропорционален стаен терморегулатор, кабел 3×0.75):
  - **X9.1** = токов сигнал **0–20 mA** (колко мощност да даде котелът → плавната модулация)
  - **X9.2** = маса
  - **+16V** захранване на термостата идва от котела (клема **X7.2**, джъмпер **J3 в позиция 2**)
- ⚠️ Сигналът е **токова примка** — да НЕ се реже жило слепешката (сгрешена посока → котел на макс).
- Котелът има и: **X12** = вход за **контактен** (вкл/изкл) термостат; **вграден седмичен програматор** `Pr.1`/`Pr.2` (нощ работи / ден спира, пази модулацията); меню `TR Type` (1=контактен, 2=пропорционален).

**План (Tuya реле — купено, виж модела по-долу):**
- **Слой 1 (без риск):** седмичен програматор на котела `Pr.1` ~23:00 ON / ~06:00 OFF.
- **Слой 2 (умно/дистанционно):** Tuya реле като **главен ключ**, прекъсва **+16V линията на термостата** (НЕ сигнала), на **COM + NC** (fail-safe: повреда/без WiFi → NC затворен → отопление работи). Реле ON = блокира (котелът вижда „няма заявка" → спира).
- Клемната работа при котела → **електротехник/сервиз Ekotermal**. При първо пускане **тест**: при „блокирам" котелът да отива на минимум, не на макс.

**Tuya реле (купено):** „1CH Wi-Fi Switch Module-DC", сухи контакти **COM/NO/NC**, 10A; захранване L/N 230V (или DC12-48 / DC5V); вход S1 за външен ключ; тънко бяло-синьо жило = WiFi антена. Образец на схемата му — на снимките в чата.

**Следваща стъпка:** сдвояване в **Smart Life** (акаунт най-вероятно `regalux@abv.bg`), тест на лампа, после автоматики (нощ/ден + по прогноза). Чакам „релето е в Smart Life".
