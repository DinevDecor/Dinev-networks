- **ffmpeg** е качен на лаптопа (в `%TEMP%\ffmpeg\...`) за вадене на кадри от записа (RTSP playback, порт 554).

### Чести задачи
- Текущ кадър: `snapshot.cgi?channel=N`.
- Кадър от записа в даден час: ffmpeg + RTSP `/cam/playback?channel=N&starttime=...&endtime=...`.
- „Кой е влизал": търсене в записа по време (няма автоматичен списък — записът е непрекъснат).
